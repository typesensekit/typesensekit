"@typesensekit/cli": minor

Make the CLI faster to learn from a shell. `tsk` and `tsk --help` now open with a quick-start cheat sheet, and `tsk operations` prints it on stderr so its stdout stays the plain `name<TAB>summary` list. Every input field can be passed as a `--<field> value` flag, and search/export accept Typesense parameters as flags (`tsk search products --filter-by 'price:<100' --per-page 0 --compact`) or as flat `--input` keys, with `q` defaulting to `*`. `collections list|retrieve --compact` prints a short overview with document counts, aliases and field facet/sort flags. When a cluster is configured, `tsk`, `tsk --help` and `tsk operations` also show that overview for the connected cluster (one quick request; silent if unreachable; set `TSK_NO_OVERVIEW=1` to skip). Without `--json`, `--compact` search output is laid out densely (one hit or facet value per line, still valid JSON). `--compact` on other operations prints the same dense layout, and boolean flags accept `--facet true|false`. Extra flags on document writes set document fields (`tsk documents update products p1 --price 9.99`), and singular group names resolve (`tsk key create`). Operation help shows descriptions and field docs, `yes: true` in `--input` confirms destructive operations, and errors name unknown input fields and list a collection's fields when a field name is wrong. Unknown flags and extra arguments still run the command, now with a warning on stderr. Existing commands, flags and `--json` output are unchanged.
